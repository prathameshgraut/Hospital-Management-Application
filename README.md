# Hospital Management Application

## 📌 Introduction

Hospital Management Application is a Java-based project used to manage hospital-related information.

### Modules

* Doctor Management
* Patient Management
* Appointment Management
* Staff Management

## 🛠️ Technologies

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* MySQL
* Maven
* Git & GitHub

## 📥 How to Clone the Project

### Step 1: Copy Repository URL

Copy the GitHub repository URL.

https://github.com/prathameshgraut/Hospital-Management-Application.git

### Step 2: Open Project

Open **STS / Eclipse** and import the cloned project.

### Step 3: Update Maven

Right-click on the project:

```text
Maven → Update Project → OK
```

### Step 4: Configure Database

Create the MySQL database and configure the database details in:

```text
src/main/resources/application.properties
```

### Step 5: Run Project

Right-click the project:

```text
Run As → Spring Boot App
```

The application will run on:

http://localhost:8080/
